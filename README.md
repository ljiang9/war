# war — 纸牌"战争"游戏

终端里的经典纸牌游戏 War:52 张牌均分,每轮比大小,平局就"战争"。

## 玩法

```bash
python -m war                 # 交互模式:回车出牌,q 退出
python -m war --auto 1000     # 自动模拟 1000 局并输出统计
python -m war --auto 100 --seed 42   # 可复现的模拟
```

## 规则

- 52 张牌均分给"你"和"电脑",只比点数(2 最小,A 最大),花色不参与。
- 每轮双方各亮顶牌,点数大者收走两张(放回自己牌堆底)。
- 点数相同则进入**战争**:双方各放 3 张暗牌 + 1 张明牌再比,仍平局则递归继续。
- 战争中牌不够放时,有多少放多少;放不出明牌的一方直接判负。
- 一方没牌即输。

## 设计取舍

- 牌堆用 `collections.deque`,顶牌 `popleft()`、收牌 `extend()` 都是 O(1)。
- 默认随机用 `secrets.SystemRandom`;`--seed` 时改用 `random.Random` 以保证可复现。
- 为防止极少数对局陷入超长循环,单局设有最大轮数(默认 10000),超限判平局。
  实测多个种子下约 11%–14% 的对局会撞上限(这是 War 本身的数学特性:
  某些洗牌会导致近乎无限的拉锯);其余对局平均约一千多轮结束。

## 已知局限

- 只有双人模式(你 vs 电脑),无多人对战、无存档。
- 交互模式是行输入,每轮需按回车;不支持单键出牌(需终端 raw 模式)。
- 达到最大轮数上限时会判平局——这是防无限循环的兜底。实测约 11%–14%
  的对局会触发(某些洗牌天生就是拉锯战),不是 bug。
- 教学/娱乐用小工具,不做胜率分析之外的策略建议。
